# Data

## Full dataset

Download the full MetObjects dataset:

- GitHub: https://github.com/metmuseum/openaccess/raw/master/MetObjects.csv
- Kaggle: search "Met Museum Open Access"

Place the file at `data/MetObjects.csv` before running the notebook.
The file is ~300 MB and is **not committed** (see `.gitignore`).

## Sample

`sample_metobjects.csv` - first 500 rows of the full dataset. Small enough to
commit; useful for testing the pipeline without the full download.
